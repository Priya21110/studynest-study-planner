STUDYNEST - STUDY PLANNER

Yeh ek chhoti website hai jisme tum padhai ke tasks add, complete, filter aur
delete kar sakti ho. Tasks isi browser aur isi laptop mein save rehte hain.

VS CODE MEIN KHOLNA
1. VS Code > File > Open Folder.
2. study-planner folder chuno.

CHALANA
1. index.html par right-click > Open with Live Server.
2. Live Server nahi hai to VS Code ke Extensions tab mein Live Server install
   karo. Phir index.html par right-click > Open with Live Server.
3. Browser mein website khulegi. Koi command, Python ya Node.js install nahi
   chahiye.

FILES
index.html = page ka text aur structure.
style.css = colors, spacing, buttons aur mobile design.
script.js = task add/complete/delete, filter, progress aur local save logic.

INTERVIEW MEIN DIKHANA
- Form mein task likhkar Add task dabao.
- Task ke gol button se complete karo; progress badhega.
- All / To do / Done filters dikhao.
- Browser refresh karke dikhao ki task save rehta hai.
- GitHub par upload karne ke baad GitHub Pages se public web link bana sakti ho.

LIMIT
Tasks sirf isi browser/laptop par save hote hain; cloud account ya sync nahi hai.
