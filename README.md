# StudyNest - Study Planner

A small, responsive study planner built with HTML, CSS, and JavaScript. Add study tasks, mark them complete, filter the list, and track daily progress.

## Features

- Add a task and choose a subject
- Mark tasks complete or delete them
- Filter tasks by all, to do, or done
- See a completion count and progress bar
- Keep tasks saved in the current browser with `localStorage`
- Responsive layout for smaller screens

## Run locally

Open `index.html` in a browser, or open this folder in VS Code and use the Live Server extension.

## Files

- `index.html` - page content and structure
- `style.css` - layout, colors, and responsive design
- `script.js` - task actions, progress, filters, and browser storage

## Note about saving

Tasks are saved only in the browser and device where they were added. They are not sent to a server and do not sync between devices.
